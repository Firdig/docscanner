DocScanner

DocScanner adalah aplikasi pemindai dokumen (document scanner) pintar yang dirancang untuk mendigitalkan, memotong (crop), menyesuaikan perspektif, dan mengonversi dokumen fisik menjadi berkas digital (seperti PDF atau Gambar) secara cepat dan akurat.

✨ Fitur Utama

Pemindaian Otomatis & Manual: Mendeteksi tepi dokumen (edge detection) secara presisi dari gambar kamera atau galeri.

Koreksi Perspektif: Menyesuaikan sudut pandang dokumen agar tampak rata dari atas (top-down view).

Filter Pengolahan Gambar: Menyediakan berbagai opsi filter seperti Magic Color, Grayscale, dan Black & White untuk meningkatkan keterbacaan teks.

Ekspor PDF & Gambar: Mengonversi hasil pemindaian tunggal maupun banyak halaman menjadi dokumen PDF siap pakai.

Pengenalan Teks (OCR): (Opsional) Mengekstrak teks dari hasil pemindaian agar dapat disalin dan dicari.

🛠 Teknologi yang Digunakan

Bahasa Pemrograman: Python / Java / Dart (sesuaikan dengan implementasi repositori)

Computer Vision: OpenCV (untuk deteksi tepi dan pemrosesan gambar)

Framework / UI: Custom UI / Mobile / Web Framework
